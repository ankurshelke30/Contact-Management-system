Data Structures Used

Under the hood — real DSA powering every operation

Hash Table

Contacts stored with phone as key. Average O(1) insertion, deletion & lookup.

Search O(1) Insert O(1) Delete O(1)

Binary Search Tree

Contacts indexed by name for O(log n) alphabetical search & range queries.

Search O(log n) Insert O(log n) Delete O(log n)

Linked List

Recent contacts maintained in a doubly linked list for O(1) front/back access.

Head Access O(1) Traversal O(n)

Quick Sort

Contacts sorted using Quick Sort — O(n log n) average — by name, phone, or group.

Avg O(n log n) Worst O(n²)

Binary Search

Sorted contact list supports Binary Search O(log n) for ultra-fast lookups.

Search O(log n)

Stack

Undo/Redo history implemented with a Stack — last-in-first-out semantics.

Push O(1) Pop O(1)

About This Project

ContactVault is a fully client-side Contact Management System built as a DSA (Data Structures & Algorithms) academic project. Every CRUD operation is backed by a real data structure implementation in vanilla JavaScript.

  • Hash Table for O(1) contact lookup
  • BST for sorted name traversal
  • Doubly Linked List for recent contacts
  • Quick Sort for dynamic sorting
  • Stack for undo/redo
  • Binary Search on sorted arrays
  • LocalStorage persistence
  • Dark / Light theme toggle
  • Export contacts as JSON / CSV
